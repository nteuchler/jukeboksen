## coin_moan.wav

- Work: **Ghost Monster Voice Moaning & Growling**
- Author: **qubodup**
- Source: https://opengameart.org/content/ghost-monster-voice-moaning-growling
- Download: https://opengameart.org/sites/default/files/qubodup-GhostMoans.zip
- License listed by the creator: **CC0** — https://creativecommons.org/publicdomain/zero/1.0/
- Retrieved: 2026-09-29
- Original archive member: `qubodup-GhostMoans/wav/qubodup-GhostMoan05.wav`
- Changes: renamed only; original audio unchanged.
- Format: 44,100 Hz, stereo, 16-bit PCM WAV; duration about 1.73 seconds.

This is a nonsexual ghost/monster vocal effect. Coin survival plays it once per
coin, at the normal system volume. It is bundled in Git so a replacement Pi does
not need internet access or a sound-library account to play it.
